# Radar (modo god) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Branch:** implement this on its **own branch created from `main`** (`feature/god-radar`), and only once no other
> code work is running in the repo. Do not start it on `feature/player-comparator`.

**Goal:** a hidden `/radar` page, reached by clicking the GOD chip. It shows each manager's balance as a range (real
cash for the connected account), squad value and total, plus a radar of buyout clauses: state, countdowns, opportunity
and which rivals can pay each one.

**Architecture:**
- **Snapshots**: `season:sync-manager-players` (every minute) stores:
  - hourly `teamMoney` snapshots, which only the connected account receives;
  - the **clause history**: a row whenever a clause or its lock changes, which later proves raises exactly.
- **Services** (`app/Services`), all pure given the DB:
  - `DailyBonusCalendar`: the daily bonus, with its fixed list of breaks.
  - `ClauseRaiseDetector`: paid raises. Exact from the history; otherwise inferred at unlock or shield expiry, with
    accepted offers skipped.
  - `ManagerBalances` / `ManagerBalance`: activity, claimed daily bonus, calibration measured on the connected
    account, range, real cash and squad value.
  - `ClauseRadar`: state, opportunity and payer levels.
- **Page**: `GodRadarController`, behind an `EnsureGodMode` middleware (404 without god mode), renders the Inertia page
  `god/radar`.
- **Privacy**: nothing reaches `/api/*`, and a guard test enforces it.

**Tech Stack:** Laravel (PHP 8.5), Pest, Inertia v3 + React + TypeScript, Tailwind (Comando HQ tokens), lucide-react,
Wayfinder.

**Spec:** `docs/superpowers/specs/2026-09-30-radar-design.md`. Background: `comando-lechuga-research/god-mode/PLAN.md`.
Approved mock: `public/_radar-a.html`.

## Global Constraints

- **Commands**: run PHP through Herd: `herd php artisan …`, `herd php vendor/bin/pint --dirty --format agent`,
  `herd php vendor/bin/phpstan analyse --memory-limit=2G`.
- **Tests**: run with `herd php artisan test --compact <path>`.
- **Frontend**: build with `npm run build` and check with `npm run types:check` and `npm run lint:check`. Never start
  `npm run dev`.
- **PHP style**:
  - every PHP file under `app/` and `database/` starts with `declare(strict_types=1);`;
  - constructor promotion, explicit return types, curly braces everywhere, PHPDoc array shapes.
- **AGENTS.md**: string columns that don't store an enum are non-nullable with default `''`. The new table has none.
- **No new base folders or dependencies.** Services go in `app/Services/`, enums in `app/Enums/`.
- **PRIVACY (hard rule):** balances, real `teamMoney`, snapshots, the daily bonus, raises, totals and all radar data
  never appear in any `/api/*` response or in `resources/docs/api-docs.md`, in any form. Do not add any of it to API
  resources or controllers.
- **Model constants**, copied verbatim from the spec:
  - starting cash 100.000.000;
  - daily bonus 100.000, or 200.000 on break days, **assumed claimed every day since joining** (both ends);
  - breaks `[['2026-09-21', '2026-10-04']]`, inclusive;
  - raising a clause by X costs X/2;
  - base clause `max(price paid, 1.000.000)`;
  - reference `max(base, max market value since the purchase)`;
  - anchors: unlock (since + 14 days) and the day before and after, plus each shield expiry;
  - a buyout inside the victim's lock, or for a round total (multiple of 100.000 ±1), is an **accepted offer**, not a
    clause payment;
  - clause history: `jump = new − max(old, new market value)`, and when it is > 0 it's an exact raise;
  - calibration `rate = (real − (activity + bonus − certain/2)) / days in the league` of the connected account,
    applied to each rival as rate × days;
  - a raise counts only if it is > 0,5 % of the clause;
  - a raise is **certain** when it's exact or a multiple of 100.000 (±1.000) at an anchor, otherwise **possible**;
  - pessimistic = activity + bonus + calibration − (certain + possible)/2;
  - optimistic = activity + bonus + calibration − certain/2;
  - opportunity `round(100 × min(1,2, value/clause)/1,2 × (0,25 + 0,75 × min(1, average/5)))`.
- **UI**:
  - every clickable element has `cursor-pointer`;
  - functional text ≥ 11 px;
  - 390 px width without horizontal scroll;
  - reuse `Hq*` components (`HqPageHeader`, `HqLed`, `HqPositionTag`, `HqManagerChip`, `HqMarketValueDifference`,
    `HqShieldCount`, `HqEmptyState`);
  - no hazard frame (`hq-god-frame`) and no GOD labels inside the page;
  - no footnotes.
- **Commits**: one per task on the feature branch. Never merge to `main` without the user's explicit OK.

## Review Focus

- **An accepted offer between managers recorded as a buyout** (round amount, or inside the lock) must not be read as a
  clause raise. Pinned in Task 5.
- **A manual raise for a holding that the sync or the inference also caught** must count once, with the user's figure.
  Pinned in Task 9.
- **A manager with no `joined_league` activity** (joined before the activity feed was synced) must still get a daily
  bonus, counted from the season `start_date`. Pinned in Task 6.
- **The connected account's snapshot is older than its latest moves** (the snapshot is at most hourly, the sync runs
  every minute). Real cash must add the activity after `captured_at`. Pinned in Task 6.
- **A clause whose `buyout_clause_locked_until` equals now** must read as open, not locked. Pinned in Task 7.
- **A player on a squad without a `PlayerSeason` row for the season** (just promoted, not synced yet) must be skipped
  by the radar, not crash it. Pinned in Task 7.
- **No snapshot at all** (fresh install, or the sync never saw `teamMoney`): the page must render with every manager
  as a range and `connectedManagerId = null`, and the payers must then include every rival. Pinned in Task 8.

```php
    /**
     * Keeps the connected account's real cash, at most once per manager and
     * hour (the command runs every minute). Rivals come back with a null
     * `teamMoney` and are skipped.
     */
    private function snapshotTeamMoney(SeasonManager $seasonManager, mixed $teamMoney): void
    {
        if (!is_numeric($teamMoney)) {
            return;
        }

        $hasRecentSnapshot = ManagerBalanceSnapshot::query()
            ->where('season_manager_id', $seasonManager->id)
            ->where('captured_at', '>', now()->subHour())
            ->exists();

        if ($hasRecentSnapshot) {
            return;
        }

        ManagerBalanceSnapshot::query()->create([
            'season_manager_id' => $seasonManager->id,
            'money' => (int) $teamMoney,
            'captured_at' => now(),
        ]);
    }
```

**Why:** `manager_players` only keeps each player's **current** clause. The sync runs **every minute** (`bootstrap/app.php`)
and the provider sends no history or raise fields per player. It only sends `buyoutClause`,
`buyoutClauseLockedEndTime`, `isShielded`, `shieldedEndDate` and `playerMaster.marketValue`.

We store a row only when the clause or its lock changes. Take two consecutive rows of the same holding (same manager and
player). The formula below tells us whether the manager paid to raise the clause, how much, and when; the cost is half
of `jump`:

```
jump = new clause − max(old clause, new market value)
```

This is exact whenever `jump > 0`, because the automatic raise (the clause following the value) never goes above the
market value. At a one-minute cadence, two events only merge if a raise and a value update land in the same minute. Even
then the formula stays right, because it uses the market value sent in that same response.

**Interfaces:**
- Produces the `ManagerPlayerClauseSnapshot` model: `season_manager_id: int`, `player_id: int`, `buyout_clause: int`,
  `buyout_clause_locked_until: CarbonImmutable`, `market_value: int`, `captured_at: CarbonImmutable`. It has a
  `seasonManager()` relation and a factory.

```php
<?php

declare(strict_types=1);

namespace App\Services;

use Carbon\CarbonImmutable;

/**
 * The daily bonus a manager claims by pressing a button once a day:
 * 100.000 €, or 200.000 € during a break without LaLiga jornadas. The feed
 * doesn't record it, but managers normally claim it, so the balance model
 * assumes every day since joining was claimed.
 */
final class DailyBonusCalendar
{
    public const int REGULAR_AMOUNT = 100_000;

    public const int BREAK_AMOUNT = 200_000;

    /**
     * Inclusive date ranges without LaLiga jornadas. Add new breaks here.
     *
     * @var list<array{0: string, 1: string}>
     */
    public const array BREAKS = [
        ['2026-09-21', '2026-10-04'],
    ];

    public function amountOn(CarbonImmutable $day): int
    {
        $date = $day->toDateString();

        foreach (self::BREAKS as [$from, $to]) {
            if ($date >= $from && $date <= $to) {
                return self::BREAK_AMOUNT;
            }
        }

        return self::REGULAR_AMOUNT;
    }

    /** Every day from the joining day up to today, both included. */
    public function totalSince(CarbonImmutable $joinedAt, CarbonImmutable $today): int
    {
        $total = 0;
        $lastDay = $today->startOfDay();

        for ($day = $joinedAt->startOfDay(); $day->lessThanOrEqualTo($lastDay); $day = $day->addDay()) {
            $total += $this->amountOn($day);
        }

        return $total;
    }
}
```

**Method** (validated on the local data; see `comando-lechuga-research/god-mode/detector2.php`):

1. **Holding.** Each player has one current holding per manager: the manager, a base and a since date.
   - After a purchase (`signing` or `buyout`), the base is `max(price, 1 M)` and since is the purchase.
   - For the initial squad, the base is `max(1 M, value on the joining day)` and since is the `joined_league` date.
   - A `sale` ends the holding.
2. **Automatic raise.** The clause follows the value up and never goes down:
   `ref(t) = max(base, max market value from since to t)`.
3. **Holdings with clause history** (Task 2). The part before the first snapshot is inferred (step 4) with that first
   snapshot's clause. After that, every jump `new − max(old, new market value) > 0` is an **exact** raise, which counts
   as certain.
4. **Holdings without history** (inference). If `clause − ref(now or buyout) ≤ 0,5 %`, there is no raise. Otherwise the
   detector tries these anchors, in order:
   - **the unlock day**: the raise is always made on the last day, just before the clause opens, because raising
     earlier wastes money when the clause rises with the value anyway. The clause just before the unlock is
     `ref(unlock day)`, or `ref(the day before)` when the unlock is earlier than that day's market update. Koski
     (Gauchitos) matches on the unlock day and Otto (CID, unlock at 00:54) on the day before;
   - **as a fallback, every shield expiry** of that player by that owner (the shield moment and shield + 24 h).

   The first anchor where `clause − ref(anchor)` is a multiple of 100.000 € (±1.000) is a **certain** raise of that
   amount. If no anchor matches, it's a **possible** raise of `clause − ref(unlock)`.
5. **Buyouts** (the victim's clause at that moment). A buyout **inside the victim's 14-day lock**, or whose amount is a
   **round total** (a multiple of 100.000 € ±1), is an **accepted offer between managers**, not a clause payment, so
   it's skipped. Today that's 25 of the 91 buyouts; 17 of them happened inside the lock.

```php
    public const int ROUND_TOLERANCE = 1_000;

            ->where('type', SeasonActivityType::JoinedLeague)

        $this->shields = [];

        foreach ($activities->where('type', SeasonActivityType::Shield)->whereNotNull('player_id') as $shield) {
            $this->shields[$shield->source_season_manager_id][(int) $shield->player_id][] = $shield->occurred_at;
        }

        $moves = $activities->filter(fn (Activity $activity): bool => $activity->player_id !== null
            && in_array($activity->type, [SeasonActivityType::Signing, SeasonActivityType::Buyout, SeasonActivityType::Sale], true));
        $owned = ManagerPlayer::query()
            ->whereHas('seasonManager', fn ($query) => $query->where('season_id', $season->id))
            ->get();
        $this->values = $this->marketValues($moves->pluck('player_id')->merge($owned->pluck('player_id'))->unique()->values()->all());
        $this->history = ManagerPlayerClauseSnapshot::query()
            ->whereHas('seasonManager', fn ($query) => $query->where('season_id', $season->id))
            ->orderBy('captured_at')
            ->orderBy('id')
            ->get()
            ->groupBy(fn (ManagerPlayerClauseSnapshot $snapshot): string => "{$snapshot->season_manager_id}:{$snapshot->player_id}")
            ->all();

        /** @var array<int, array{manager_id: int, base: int, since: CarbonImmutable}> $holdings */
        $holdings = [];

        foreach ($moves as $move) {
            $playerId = (int) $move->player_id;
            $amount = (int) $move->amount;

            if ($move->type === SeasonActivityType::Buyout && $move->target_season_manager_id !== null) {
                $victimId = $move->target_season_manager_id;
                [$base, $since] = $this->holding($holdings[$playerId] ?? null, $victimId, $playerId, $season);

                if (!$this->isOffer($amount, $since, $move->occurred_at)) {
                    $this->holdingRaises($victimId, $playerId, $base, $since, $amount, $move->occurred_at);
                }
            }

            if ($move->type === SeasonActivityType::Sale) {
                unset($holdings[$playerId]);

                continue;
            }

            $holdings[$playerId] = ['manager_id' => $move->source_season_manager_id, 'base' => max(self::MIN_CLAUSE, $amount), 'since' => $move->occurred_at];
        }

        foreach ($owned as $entry) {
            [$base, $since] = $this->holding($holdings[$entry->player_id] ?? null, $entry->season_manager_id, $entry->player_id, $season);
            $this->holdingRaises($entry->season_manager_id, $entry->player_id, $base, $since, $entry->buyout_clause, $now);
        }

        return $this->raises;
    }

    /**
     * @param  array{manager_id: int, base: int, since: CarbonImmutable}|null  $holding
     * @return array{0: int, 1: CarbonImmutable}
     */
    private function holding(?array $holding, int $managerId, int $playerId, Season $season): array
    {
        if ($holding !== null && $holding['manager_id'] === $managerId) {
            return [$holding['base'], $holding['since']];
        }

        $since = $this->joinedAt[$managerId] ?? $season->start_date;

        return [max(self::MIN_CLAUSE, $this->valueAt($playerId, $since) ?? 0), $since];
    }

    /** An accepted offer between managers: inside the victim's lock, or a round total. */
    private function isOffer(int $amount, CarbonImmutable $since, CarbonImmutable $at): bool
    {
        return $at->lessThan($since->addDays(self::LOCK_DAYS)) || $this->isRound($amount, 1);
    }

    /** Exact raises from the clause history when there is one; otherwise the inference. */
    private function holdingRaises(int $managerId, int $playerId, int $base, CarbonImmutable $since, int $clause, CarbonImmutable $at): void
    {
        $snapshots = ($this->history["{$managerId}:{$playerId}"] ?? collect())
            ->filter(fn (ManagerPlayerClauseSnapshot $snapshot): bool => $snapshot->captured_at->betweenIncluded($since, $at))
            ->values();

        if ($snapshots->isEmpty()) {
            $this->infer($managerId, $playerId, $base, $since, $clause, $at);

            return;
        }

        $first = $snapshots->first();
        $this->infer($managerId, $playerId, $base, $since, $first->buyout_clause, $first->captured_at);

        $snapshots->sliding(2)->each(function (Collection $pair) use ($managerId): void {
            [$previous, $current] = $pair->values()->all();
            $jump = $current->buyout_clause - max($previous->buyout_clause, $current->market_value);

            if ($jump > $current->buyout_clause * self::NOISE_RATIO) {
                $this->add($managerId, 'sure', $jump);
            }
        });
    }

    private function infer(int $managerId, int $playerId, int $base, CarbonImmutable $since, int $clause, CarbonImmutable $at): void
    {
        if ($clause - $this->reference($playerId, $base, $since, $at) <= $clause * self::NOISE_RATIO) {
            return;
        }

        $unlock = $since->addDays(self::LOCK_DAYS);
        $anchors = [$unlock, $unlock->subDay()];

        foreach ($this->shields[$managerId][$playerId] ?? [] as $shieldedAt) {
            if ($shieldedAt->betweenIncluded($since, $at)) {
                $anchors[] = $shieldedAt;
                $anchors[] = $shieldedAt->addDay();
            }
        }

        foreach ($anchors as $anchor) {
            if ($anchor->greaterThan($at)) {
                continue;
            }

            $raise = $clause - $this->reference($playerId, $base, $since, $anchor);

            if ($raise > $clause * self::NOISE_RATIO && $this->isRound($raise, self::ROUND_TOLERANCE)) {
                $this->add($managerId, 'sure', $raise);

                return;
            }
        }

        $this->add($managerId, 'possible', $clause - $this->reference($playerId, $base, $since, $unlock->lessThan($at) ? $unlock : $at));
    }

    private function reference(int $playerId, int $base, CarbonImmutable $since, CarbonImmutable $until): int
    {
        $from = $since->toDateString();
        $to = $until->toDateString();
        $max = 0;

        foreach ($this->values[$playerId] ?? [] as [$date, $value]) {
            if ($date >= $from && $date <= $to) {
                $max = max($max, $value);
            }
        }

        return max($base, $max);
    }

    private function valueAt(int $playerId, CarbonImmutable $day): ?int
    {
        $found = null;

        foreach ($this->values[$playerId] ?? [] as [$date, $value]) {
            if ($date <= $day->toDateString()) {
                $found = $value;
            }
        }

        return $found;
    }

    private function isRound(int $amount, int $tolerance): bool
    {
        return abs($amount - (int) round($amount / self::ROUND_STEP) * self::ROUND_STEP) <= $tolerance;
    }

    /** @param 'sure'|'possible' $bucket */
    private function add(int $managerId, string $bucket, int $raise): void
    {
        $this->raises[$managerId] ??= ['sure' => 0, 'possible' => 0];
        $this->raises[$managerId][$bucket] += $raise;
    }

    /**
     * @param  list<int>  $playerIds
     * @return array<int, list<array{0: string, 1: int}>>
     */
    private function marketValues(array $playerIds): array
    {
        $values = [];

        PlayerMarket::query()
            ->whereIn('player_id', $playerIds)
            ->orderBy('date')
            ->get(['player_id', 'date', 'value'])
            ->each(function (PlayerMarket $market) use (&$values): void {
                $values[(int) $market->player_id][] = [$market->date->toDateString(), $market->value];
            });

        return $values;
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Services;

/**
 * A manager's cash as a range.
 * - Certain: activity, the claimed daily bonus, and the calibration measured on the connected account.
 * - Pessimistic end: also pays every inferred clause raise at half its amount.
 * - Optimistic end: pays only the certain raises.
 * The connected account has its real cash instead. PRIVATE: web /radar only.
 */
final readonly class ManagerBalance
{
    public function __construct(
        public int $seasonManagerId,
        public int $activity,
        public int $dailyBonus,
        public int $sureRaises,
        public int $possibleRaises,
        public ?int $real,
        public int $squadValue,
        public int $calibration = 0,
    ) {}

    public function isReal(): bool
    {
        return $this->real !== null;
    }

    public function low(): int
    {
        return $this->real ?? $this->base() - intdiv($this->sureRaises + $this->possibleRaises, 2);
    }

    public function high(): int
    {
        return $this->real ?? $this->base() - intdiv($this->sureRaises, 2);
    }

    public function mid(): int
    {
        return intdiv($this->low() + $this->high(), 2);
    }

    /**
     * @return array{cash: array{low: int, high: int, mid: int, is_real: bool}, squad_value: int, total: array{low: int, high: int, mid: int}}
     */
    public function toArray(): array
    {
        return [
            'cash' => ['low' => $this->low(), 'high' => $this->high(), 'mid' => $this->mid(), 'is_real' => $this->isReal()],
            'squad_value' => $this->squadValue,
            'total' => [
                'low' => $this->low() + $this->squadValue,
                'high' => $this->high() + $this->squadValue,
                'mid' => $this->mid() + $this->squadValue,
            ],
        ];
    }

    private function base(): int
    {
        return $this->activity + $this->dailyBonus + $this->calibration;
    }
}
```

```php
<?php

declare(strict_types=1);

namespace App\Services;

use App\Enums\SeasonActivityType;
use App\Models\Activity;
use App\Models\ManagerBalanceSnapshot;
use App\Models\ManagerPlayer;
use App\Models\Season;
use App\Models\SeasonManager;
use Carbon\CarbonImmutable;

/**
 * Every manager's cash range, squad value and total for the god-mode radar.
 * PRIVATE: never used by /api.
 */
final class ManagerBalances
{
    public const int STARTING_CASH = 100_000_000;

    public function __construct(
        private readonly DailyBonusCalendar $dailyBonus,
        private readonly ClauseRaiseDetector $raiseDetector,
    ) {}

    /**
     * @return array<int, ManagerBalance> season manager id => balance
     */
    public function forSeason(Season $season, CarbonImmutable $now): array
    {
        $managers = SeasonManager::query()->where('season_id', $season->id)->get();
        $activity = $this->activitySums($season);
        $raises = $this->raiseDetector->forSeason($season, $now);
        $squad = $this->squadValues($season);
        $snapshots = ManagerBalanceSnapshot::query()
            ->whereIn('season_manager_id', $managers->pluck('id'))
            ->orderByDesc('captured_at')
            ->get()
            ->unique('season_manager_id')
            ->keyBy('season_manager_id');
        $joinedAt = Activity::query()
            ->where('season_id', $season->id)
            ->where('type', SeasonActivityType::JoinedLeague)
            ->orderBy('occurred_at')
            ->get()
            ->unique('source_season_manager_id')
            ->mapWithKeys(fn (Activity $joined): array => [$joined->source_season_manager_id => $joined->occurred_at]);

        $balances = [];
        $days = [];
        $ratePerDay = null;

        foreach ($managers as $manager) {
            $since = $joinedAt->get($manager->id) ?? $season->start_date;
            $days[$manager->id] = (int) $since->startOfDay()->diffInDays($now->startOfDay()) + 1;
            $snapshot = $snapshots->get($manager->id);
            $real = $snapshot instanceof ManagerBalanceSnapshot
                ? $snapshot->money + ($this->activitySums($season, $snapshot->captured_at)[$manager->id] ?? 0)
                : null;

            $balances[$manager->id] = new ManagerBalance(
                seasonManagerId: $manager->id,
                activity: self::STARTING_CASH + ($activity[$manager->id] ?? 0),
                dailyBonus: $this->dailyBonus->totalSince($since, $now),
                sureRaises: $raises[$manager->id]['sure'] ?? 0,
                possibleRaises: $raises[$manager->id]['possible'] ?? 0,
                real: $real,
                squadValue: (int) ($squad[$manager->id] ?? 0),
            );
        }

        $connectedId = $this->connectedManagerId($season);

        if ($connectedId !== null && isset($balances[$connectedId]) && $balances[$connectedId]->real !== null) {
            $connected = $balances[$connectedId];
            $model = $connected->activity + $connected->dailyBonus - intdiv($connected->sureRaises, 2);
            $ratePerDay = ($connected->real - $model) / max(1, $days[$connectedId]);
        }

        if ($ratePerDay === null) {
            return $balances;
        }

        foreach ($balances as $managerId => $balance) {
            if ($balance->real !== null) {
                continue;
            }

            $balances[$managerId] = new ManagerBalance(
                $balance->seasonManagerId, $balance->activity, $balance->dailyBonus, $balance->sureRaises,
                $balance->possibleRaises, null, $balance->squadValue, (int) round($ratePerDay * $days[$managerId]),
            );
        }

        return $balances;
    }

    /** The manager whose real cash we see: the owner of the latest snapshot this season. */
    public function connectedManagerId(Season $season): ?int
    {
        $managerId = ManagerBalanceSnapshot::query()
            ->whereHas('seasonManager', fn ($query) => $query->where('season_id', $season->id))
            ->orderByDesc('captured_at')
            ->value('season_manager_id');

        return $managerId === null ? null : (int) $managerId;
    }

    /**
     * Signed money moves per manager, optionally only after a moment.
     *
     * @return array<int, int>
     */
    private function activitySums(Season $season, ?CarbonImmutable $after = null): array
    {
        $sums = [];

        Activity::query()
            ->where('season_id', $season->id)
            ->when($after, fn ($query) => $query->where('occurred_at', '>', $after))
            ->get(['type', 'source_season_manager_id', 'target_season_manager_id', 'amount'])
            ->each(function (Activity $activity) use (&$sums): void {
                $amount = (int) $activity->amount;
                $source = $activity->source_season_manager_id;

                match ($activity->type) {
                    SeasonActivityType::Sale, SeasonActivityType::WeeklyPrize => $sums[$source] = ($sums[$source] ?? 0) + $amount,
                    SeasonActivityType::Signing => $sums[$source] = ($sums[$source] ?? 0) - $amount,
                    SeasonActivityType::Buyout => $this->applyBuyout($sums, $source, $activity->target_season_manager_id, $amount),
                    default => null,
                };
            });

        return $sums;
    }

    /**
     * @param  array<int, int>  $sums
     */
    private function applyBuyout(array &$sums, int $payerId, ?int $receiverId, int $amount): void
    {
        $sums[$payerId] = ($sums[$payerId] ?? 0) - $amount;

        if ($receiverId !== null) {
            $sums[$receiverId] = ($sums[$receiverId] ?? 0) + $amount;
        }
    }

    /**
     * @return array<int, int> season manager id => sum of current market values
     */
    private function squadValues(Season $season): array
    {
        return ManagerPlayer::query()
            ->join('season_managers', 'season_managers.id', '=', 'manager_players.season_manager_id')
            ->join('player_seasons', function ($join) use ($season): void {
                $join->on('player_seasons.player_id', '=', 'manager_players.player_id')
                    ->where('player_seasons.season_id', '=', $season->id);
            })
            ->where('season_managers.season_id', $season->id)
            ->groupBy('manager_players.season_manager_id')
            ->selectRaw('manager_players.season_manager_id as manager_id, SUM(player_seasons.market_value) as total')
            ->pluck('total', 'manager_id')
            ->map(fn (mixed $total): int => (int) $total)
```

```php
<?php

declare(strict_types=1);

namespace App\Services;

use App\Enums\ClauseState;
use App\Enums\PayerLevel;
use App\Models\ManagerPlayer;
use App\Models\MarketPlayer;
use App\Models\PlayerSeason;
use App\Models\Season;
use Carbon\CarbonImmutable;

/**
 * Every squad player's buyout clause with its state, opportunity and which
 * rivals can pay it. PRIVATE: web /radar only.
 *
 * @phpstan-type RadarClauseShape array{player: array{id: int, nickname: string, position: string, team_short_name: string, points: int, average_points: float, status: string, market_value: int, market_value_difference: int, market_trend: string|null}, owner_id: int, amount: int, locked_until: string, shielded_until: string|null, state: string, opportunity: int, payers: list<array{manager_id: int, level: string}>}
 */
final class ClauseRadar
{
    public function __construct(private readonly ClauseOpportunityParameters $parameters) {}

    public static function state(ManagerPlayer $entry, bool $listed, CarbonImmutable $now): ClauseState
    {
        if ($listed) {
            return ClauseState::Listed;
        }

        if ($entry->shielded && $entry->shielded_until !== null && $entry->shielded_until->greaterThan($now)) {
            return ClauseState::Shielded;
        }

        return $entry->buyout_clause_locked_until->greaterThan($now) ? ClauseState::Locked : ClauseState::Open;
    }

    public static function payerLevel(ManagerBalance $balance, int $clause): PayerLevel
    {
        if ($balance->low() >= $clause) {
            return PayerLevel::Sure;
        }

        return $balance->high() >= $clause ? PayerLevel::Maybe : PayerLevel::No;
    }

    public function opportunity(int $clause, int $value, float $average): int
    {
        $ratio = min($this->parameters->valueRatioCap, $value / max(1, $clause)) / $this->parameters->valueRatioCap;
        $form = $this->parameters->formFloor + $this->parameters->formWeight * min(1.0, $average / $this->parameters->averageTarget);

        return (int) round(100 * $ratio * $form);
    }

    /**
     * @param  array<int, ManagerBalance>  $balances
     * @return list<RadarClauseShape>
     */
    public function forSeason(Season $season, array $balances, ?int $connectedManagerId, CarbonImmutable $now): array
    {
        $listed = array_flip(MarketPlayer::query()->pluck('player_id')->all());
        $rows = [];

        $entries = ManagerPlayer::query()
            ->whereHas('seasonManager', fn ($query) => $query->where('season_id', $season->id))
            ->with(['player.team', 'player.seasons' => fn ($query) => $query->where('season_id', $season->id)])
            ->get();

        foreach ($entries as $entry) {
            $playerSeason = $entry->player->seasons->first();

            if (!$playerSeason instanceof PlayerSeason) {
                continue;
            }

            $payers = [];

            foreach ($balances as $managerId => $balance) {
                if ($managerId === $entry->season_manager_id || $managerId === $connectedManagerId) {
                    continue;
                }

                $payers[] = ['manager_id' => $managerId, 'level' => self::payerLevel($balance, $entry->buyout_clause)->value];
            }

            $rows[] = [
                'player' => [
                    'id' => $entry->player->id,
                    'nickname' => $entry->player->nickname,
                    'position' => $playerSeason->position->value,
                    'team_short_name' => $entry->player->team?->short_name ?? '',
                    'points' => $playerSeason->points,
                    'average_points' => (float) $playerSeason->average_points,
                    'status' => $entry->player->status->value,
                    'market_value' => $playerSeason->market_value,
                    'market_value_difference' => $playerSeason->market_value_difference,
                    'market_trend' => $playerSeason->market_trend?->value,
                ],
                'owner_id' => $entry->season_manager_id,
                'amount' => $entry->buyout_clause,
                'locked_until' => $entry->buyout_clause_locked_until->toIso8601String(),
                'shielded_until' => $entry->shielded_until?->toIso8601String(),
                'state' => self::state($entry, isset($listed[$entry->player_id]), $now)->value,
                'opportunity' => $this->opportunity($entry->buyout_clause, $playerSeason->market_value, (float) $playerSeason->average_points),
                'payers' => $payers,
            ];
        }

        return $rows;
    }
}
```

**Requirement** (user): «En el historial de cláusulas debería haber un sitio donde yo manualmente las añada.»

**How it works:**
- A manual entry is a `manager_player_clause_snapshots` row with `source = manual` (Task 2 already has `source`,
  `raise_amount` and `note`).
- The form takes either the **new clause** or the **amount paid**, and derives the other:
  - `raise = new clause − previous clause`, or `raise = paid × 2`;
  - `cost = raise / 2`;
  - `new clause = previous clause + raise`.
  - «Previous clause» is the latest history row of that holding before the moment. Without one, it is
    `max(1 M, market value that day)`.
- **Manual entries are authoritative.** For a holding with at least one manual entry:
  - the detector adds the manual raises as certain;
  - it **skips the inference** for that holding;
  - it drops any sync jump that lands within 24 h of a manual entry with the same resulting clause.

  That way nothing is counted twice.

**Interfaces:**
- Consumes: `ManagerPlayerClauseSnapshot` with `ClauseSnapshotSource` (Task 2), `ClauseRaiseDetector` (Task 5) and
  `EnsureGodMode` (Task 8).
- Produces:
  - Routes (all behind `EnsureGodMode`): `POST /radar/subidas` → `god.clause-raises.store`,
    `PUT /radar/subidas/{snapshot}` → `god.clause-raises.update` and `DELETE /radar/subidas/{snapshot}` →
    `god.clause-raises.destroy`. Update and destroy only accept `source = manual` rows (404 otherwise).
  - `ManualClauseRaise::derive(int $managerId, int $playerId, CarbonImmutable $at, ?int $newClause, ?int $paid): array{previous: int, clause: int, raise: int}`.
  - The `manualRaises` prop on `god/radar`: a list of
    `{id, player: {id, nickname}, manager_id, captured_at, clause, raise, cost, note}`.

```php
<?php

declare(strict_types=1);

namespace App\Services;

use App\Models\ManagerPlayerClauseSnapshot;
use App\Models\PlayerMarket;
use Carbon\CarbonImmutable;

/**
 * Turns a user-entered clause raise into (previous clause, new clause, raise).
 * Raising a clause by X costs X/2, so "paid" doubles into the raise.
 */
final class ManualClauseRaise
{
    /**
     * @return array{previous: int, clause: int, raise: int}
     */
    public function derive(int $managerId, int $playerId, CarbonImmutable $at, ?int $newClause, ?int $paid, ?int $ignoreId = null): array
    {
        $previous = ManagerPlayerClauseSnapshot::query()
            ->where('season_manager_id', $managerId)
            ->where('player_id', $playerId)
            ->where('captured_at', '<', $at)
            ->when($ignoreId, fn ($query) => $query->whereKeyNot($ignoreId))
            ->latest('captured_at')
            ->value('buyout_clause');
        $previous ??= max(
            ClauseRaiseDetector::MIN_CLAUSE,
            (int) PlayerMarket::query()->where('player_id', $playerId)->whereDate('date', '<=', $at)->latest('date')->value('value'),
        );
        $previous = (int) $previous;

        $raise = $newClause !== null ? $newClause - $previous : (int) $paid * 2;

        return ['previous' => $previous, 'clause' => $previous + $raise, 'raise' => $raise];
    }
}
```

```ts
/** Time left to unlock: "2 d 14 h 03 min", "5 h 07 min", and with seconds in the last hour: "42 min 07 s". */
export function formatUnlockCountdown(ms: number): string {
    const totalSeconds = Math.max(0, Math.floor(ms / 1000));
    const days = Math.floor(totalSeconds / 86400);
    const hours = Math.floor((totalSeconds % 86400) / 3600);
    const minutes = Math.floor((totalSeconds % 3600) / 60);
    const seconds = totalSeconds % 60;
    const pad = (value: number) => String(value).padStart(2, '0');

    if (days > 0) {
        return `${days} d ${pad(hours)} h ${pad(minutes)} min`;
    }

    if (hours > 0) {
        return `${hours} h ${pad(minutes)} min`;
    }

    return `${minutes} min ${pad(seconds)} s`;
}
```

```tsx
import { useState } from 'react';
```

```tsx
import type { RadarClause, RadarManager, RadarManualRaise } from '@/types/models';

type Mode = 'new_clause' | 'paid';

const field = 'min-h-8 w-full border border-hq-border-strong bg-hq-panel px-2 font-mono text-xs text-hq-paper';

/** «Subidas conocidas»: add, edit and delete clause raises the user knows about; they override the inference. */
export function RadarManualRaises({ entries, managers, clauses }: { entries: RadarManualRaise[]; managers: RadarManager[]; clauses: RadarClause[] }) {
    const byId = new Map(managers.map((m) => [m.id, m]));
    const [editing, setEditing] = useState<RadarManualRaise | null>(null);
    const [mode, setMode] = useState<Mode>('new_clause');
    const form = useForm({ season_manager_id: '', player_id: '', captured_at: '', new_clause: '', paid: '', note: '' });
    const amount = mode === 'new_clause' ? form.data.new_clause : form.data.paid;

    const startEdit = (entry: RadarManualRaise) => {
        setEditing(entry);
        setMode('new_clause');
        form.setData({ season_manager_id: String(entry.manager_id), player_id: String(entry.player.id), captured_at: entry.captured_at.slice(0, 16), new_clause: String(entry.clause), paid: '', note: entry.note });
    };

    const submit = (event: React.FormEvent) => {
        event.preventDefault();
        form.transform((data) => ({ ...data, new_clause: mode === 'new_clause' ? data.new_clause : null, paid: mode === 'paid' ? data.paid : null }));
        const options = { preserveScroll: true, onSuccess: () => { form.reset(); setEditing(null); } };

        if (editing) {
            form.put(update(editing.id).url, options);
        } else {
            form.post(store().url, options);
        }
    };

    return (
        <section aria-labelledby="radar-manual" className="border-t border-hq-border-strong">
            <h2 id="radar-manual" className="flex items-center gap-1.5 px-3.5 pt-3 pb-2 text-[15px] font-black uppercase">
                <Pencil aria-hidden="true" className="size-4 text-hq-moss" />
                Subidas conocidas
                <small className="font-mono text-xs font-semibold text-hq-moss-dim normal-case">{entries.length}</small>
            </h2>

            <form onSubmit={submit} className="grid grid-cols-2 gap-2 px-3.5 pb-3 sm:grid-cols-[1fr_1fr_170px_auto_130px_1fr_auto] sm:items-end">
                <label className="flex flex-col gap-1">
                    <span className="hq-label">Mánager</span>
                    <select className={cn(field, 'cursor-pointer')} value={form.data.season_manager_id} onChange={(e) => form.setData('season_manager_id', e.target.value)}>
                        <option value="">—</option>
                        {managers.map((m) => <option key={m.id} value={m.id}>{m.name}</option>)}
                    </select>
                </label>
                <label className="flex flex-col gap-1">
                    <span className="hq-label">Jugador</span>
                    <select className={cn(field, 'cursor-pointer')} value={form.data.player_id} onChange={(e) => form.setData('player_id', e.target.value)}>
                        <option value="">—</option>
                        {clauses
                            .filter((c) => !form.data.season_manager_id || c.owner_id === Number(form.data.season_manager_id))
                            .map((c) => <option key={c.player.id} value={c.player.id}>{c.player.nickname}</option>)}
                    </select>
                </label>
                <label className="flex flex-col gap-1">
                    <span className="hq-label">Cuándo</span>
                    <input type="datetime-local" className={field} value={form.data.captured_at} onChange={(e) => form.setData('captured_at', e.target.value)} />
                </label>
                <div role="group" aria-label="Qué importe" className="col-span-2 flex border border-hq-border-strong sm:col-span-1">
                    {(['new_clause', 'paid'] as const).map((option) => (
                        <button key={option} type="button" aria-pressed={mode === option} onClick={() => setMode(option)}
                            className={cn('min-h-8 flex-1 cursor-pointer px-2 font-mono text-[11px] font-bold uppercase', mode === option ? 'bg-hq-lime text-hq-ink' : 'text-hq-moss hover:bg-hq-panel')}>
                            {option === 'new_clause' ? 'Nueva cláusula' : 'Pagado'}
                        </button>
                    ))}
                </div>
                <label className="flex flex-col gap-1">
                    <span className="hq-label">{mode === 'new_clause' ? 'Cláusula €' : 'Pagado €'}</span>
                    <input inputMode="numeric" className={field} value={amount}
                        onChange={(e) => form.setData(mode, e.target.value.replace(/\D/g, ''))} />
                </label>
                <label className="flex flex-col gap-1">
                    <span className="hq-label">Nota</span>
                    <input className={field} maxLength={255} value={form.data.note} onChange={(e) => form.setData('note', e.target.value)} />
                </label>
                <button type="submit" disabled={form.processing}
                    className="inline-flex min-h-8 cursor-pointer items-center justify-center gap-1.5 border border-hq-lime/50 px-3 font-mono text-[11.5px] font-bold text-hq-lime uppercase hover:bg-hq-lime hover:text-hq-ink disabled:cursor-not-allowed disabled:opacity-50">
                    <Plus aria-hidden="true" className="size-3" />
                    {editing ? 'Guardar' : 'Añadir'}
                </button>
                {Object.values(form.errors).length > 0 && (
                    <p role="alert" className="col-span-full font-mono text-[11.5px] text-hq-neg">{Object.values(form.errors)[0]}</p>
                )}
            </form>

            {entries.map((entry) => {
                const manager = byId.get(entry.manager_id);

                return (
                    <div key={entry.id} className="grid grid-cols-[minmax(0,1fr)_auto] items-center gap-2 border-t border-hq-border px-3.5 py-1.5 sm:grid-cols-[minmax(0,1fr)_auto_auto_auto]">
                        <span className="min-w-0">
                            <b className="block truncate text-[13px] font-extrabold">{entry.player.nickname}</b>
                            <small className="flex items-center gap-1.5 font-mono text-[11px] text-hq-moss-dim">
                                {manager && <ManagerSquare manager={manager} />}
                                <span className="truncate">{manager?.name} · {formatMatchDateTime(entry.captured_at)}{entry.note && ` · ${entry.note}`}</span>

                            <button type="button" onClick={() => startEdit(entry)} aria-label={`Editar ${entry.player.nickname}`} className="flex size-8 cursor-pointer items-center justify-center border border-hq-border-strong text-hq-moss hover:text-hq-paper">

                                <Trash2 aria-hidden="true" className="size-3.5" />
                            </button>
                        </span>
```

  manager's initial inside every colour square (`ManagerSquare`).
